# Інструкція: Імпорт Даних з Excel для oiHromadaSurvey

## Швидкий Старт

### 1. Експорт Шаблону

**Варіант A: Через UI**
1. Відкрийте будь-яку групу в oiHromadaSurvey
2. Натисніть кнопку **"Дії"** → **"Імпорт даних з Excel"**
3. У діалозі виберіть організацію (опціонально)
4. Система автоматично згенерує та відкриє діалог імпорту

**Варіант B: Через API**
```javascript
frappe.call({
    method: "orange_inventory.orange_inventory.doctype.oihromadasurvey.oihromadasurvey.export_org_template",
    args: {
        org: "ORG-0001",  // ID організації
        period: "2025-Q4"  // Опціонально
    },
    callback: function(r) {
        if (r.message && r.message.file_url) {
            window.open(r.message.file_url);
        }
    }
});
```

### 2. Редагування Excel Файлу

**Структура файлу:**

| A | B | C | D | E | F | **G** | H |
|---|---|---|---|---|---|-------|---|
| Шлях | ID | Назва | Тип | Періодичність | Поточне | **РЕДАГУВАТИ** | Примітка |
| 🔒 | 🔒 | 🔒 | 🔒 | 🔒 | 🔒 | ✏️ | 🔒 |

**Важливо:**
- Редагуйте **ТІЛЬКИ колонку G** (Значення для заповнення)
- Для кількісних даних: вводьте числа (наприклад: `150`)
- Для якісних даних: вводьте `Так` або `Ні` (регістр важливий!)

**Приклад:**
```
Шлях                          | ID          | Назва              | Тип            | G: Нове значення
------------------------------|-------------|--------------------|----------------|------------------
Інфраструктура / ІТ          | comp-001    | Кількість ПК       | Кількісні      | 25
Інфраструктура / Зв'язок     | internet-01 | Наявність інтернету| Якісні         | Так
```

---

### 3. Імпорт Даних

**Через UI:**
1. Відкрийте **список показників** (oiHromadaSurvey List View)
2. Натисніть меню **"..."** → **"Імпорт даних з Excel"**
3. Завантажте відредагований файл
4. (Опціонально) Виберіть організацію для валідації
5. Натисніть **"Імпортувати"**

**Важливо:** Кнопка імпорту знаходиться в ListView (списку показників), а не в окремому документі!

**Через API:**
```python
import frappe

@frappe.whitelist()
def my_import():
    result = frappe.call(
        method="orange_inventory.orange_inventory.doctype.oihromadasurvey.oihromadasurvey.import_from_excel",
        args={
            "file_url": "/private/files/template.xlsx",
            "org": "ORG-0001"  # Опціонально
        }
    )
    return result
```

## Валідація Даних

### Кількісні дані
- ✅ Цілі числа: `0`, `10`, `150`
- ✅ Float (конвертується): `10.5` → `10`
- ❌ Від'ємні: `-5`
- ❌ Текст: `багато`

### Якісні дані
- ✅ `Так` (з великої літери)
- ✅ `Ні` (з великої літери)
- ❌ `так` (мала літера)
- ❌ `Yes`, `No`, `true`, `false`

## Часті Питання (FAQ)

### 🔍 Чому деякі записи пропущено?

Записи пропускаються якщо:
- Значення не змінилося (старе = нове)
- Показник має прапорець `only_admin` (тільки для адміністратора)
- Колонка G порожня

### ⚠️ Що робити при помилках?

1. Перегляньте список помилок у результатах
2. Виправте значення в Excel файлі
3. Повторіть імпорт

**Типові помилки:**
- `Некоректне числове значення 'текст'` → Введіть число
- `Некоректне якісне значення 'yes'` → Використайте `Так` або `Ні`
- `Показник XYZ не знайдено` → Перевірте ID показника

### 🔒 Чи можна імпортувати only_admin записи?

Ні, такі записи автоматично пропускаються для безпеки.

### 📊 Чи створюється історія при імпорті?

Так! Кожна зміна автоматично додається в історію з:
- Датою та часом
- Поточним періодом (квартал/рік)
- Користувачем який виконав імпорт

## Технічні Деталі

### Підтримувані Формати
- ✅ `.xlsx` (Excel 2007+)
- ✅ `.xls` (Excel 97-2003)

### Обмеження
- Файл має бути згенерований через `export_org_template`
- Максимальний розмір файлу: визначається налаштуваннями Frappe
- Одночасно можна імпортувати тільки один файл

### Безпека
- Валідація організації (якщо вказана)
- Пропуск `only_admin` полів
- Транзакційне збереження (все або нічого)
- Логування всіх змін

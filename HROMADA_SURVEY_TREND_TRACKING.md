# oiHromadaSurvey - Відстеження Тенденцій Змін Даних 📊

**Дата створення:** 21 жовтня 2025
**Версія:** 1.0

---

## 🎯 Огляд Функціональності

Додано можливість автоматичного відстеження історії змін показників в oiHromadaSurvey з візуалізацією тенденцій на графіках.

### Основні Можливості:

✅ **Автоматичне збереження історії** - Кожна зміна значення автоматично записується
✅ **Прив'язка до періоду** - Автоматичне визначення періоду (квартал/рік) на основі frequency
✅ **Візуалізація тенденцій** - Інтерактивні графіки Chart.js з історією змін
✅ **Підтримка обох типів даних** - Кількісні та якісні показники

---

## 📋 Структура Даних

### Новий Child DocType: oiHromadaSurveyHistory

**Поля:**

| Поле | Тип | Опис |
|------|-----|------|
| `recorded_date` | Datetime | Дата та час запису (автоматично) |
| `period` | Data | Період (2025-Q1, 2025-01, 2025) |
| `int_value` | Int | Значення для кількісних даних |
| `bool_value` | Check | Значення для якісних даних |
| `value_display` | Data | Текстове відображення ("Так"/"Ні" або число) |
| `changed_by` | Link (User) | Хто змінив значення |
| `notes` | Small Text | Додаткові примітки |

### Зміни в oiHromadaSurvey

**Додано:**
- Tab "Історія Значень" (показується тільки для листових показників)
- Child Table `value_history` типу oiHromadaSurveyHistory
- Кнопка "Показати Тенденцію" для візуалізації

## 🔧 Як Працює

### 1. Автоматичне Відстеження Змін

При збереженні документа oiHromadaSurvey:

```python
def _track_value_changes(self):
    # Відстежує зміни в int_data або bool_data
    if self.type == "Група":
        return  # Групи не відстежуються

    if self.is_new():
        return  # Нові документи пропускаємо

    # Перевіряємо зміни
    if self.has_value_changed("int_data") or self.has_value_changed("bool_data"):
        # Автоматично додаємо запис в value_history
        self.append("value_history", {
            "recorded_date": frappe.utils.now(),
            "period": self._get_current_period(),
            "int_value": self.int_data,
            "bool_value": self.bool_data,
            "value_display": display,
            "changed_by": frappe.session.user
        })
```

### 2. Визначення Періоду

Період автоматично визначається на основі поля `frequency`:

| Frequency | Формат Періоду | Приклад |
|-----------|----------------|---------|
| "Раз на квартал" | YYYY-QN | 2025-Q1 |
| "Раз на рік" | YYYY | 2025 |
| Інше | YYYY-MM | 2025-10 |

### 3. Візуалізація Тенденцій

Кнопка "Показати Тенденцію" викликає метод `get_value_trend_data()`:

```python
@frappe.whitelist()
def get_value_trend_data(survey_id: str, limit: int = 50):
    """
    Повертає дані для графіка:
    {

        "values": [10, 15, 12, ...],
        "type": "Кількісні дані",
        "title": "Назва показника",
        "frequency": "Раз на квартал"
    }
    """
```

Відображається інтерактивний лінійний графік Chart.js з:
- Осі X: Періоди
- Осі Y: Значення (для якісних даних: Так=100, Ні=0)
- Заголовок: Назва показника + періодичність

## 📥 Імпорт Даних з Excel

### Новий Функціонал: Завантаження та Оновлення Даних

**Дата додавання:** 21 жовтня 2025

#### Огляд

Додано можливість завантаження Excel файлів для масового оновлення показників. Система автоматично:
- Парсить значення з файлу
- Порівнює з поточними даними
- Оновлює тільки змінені записи
- Створює історію змін автоматично

#### Як Використовувати

1. **Експорт Шаблону**
   - Відкрити **список показників** (oiHromadaSurvey List View)
   - Натиснути меню **"..."** → **"Export Excel Template..."**
   - Вибрати розпорядника та період
   - Або використати API метод `export_org_template(org_id, period)`

2. **Редагування Файлу**
   - Відкрити згенерований Excel файл
   - Знайти колонку **"G"** (Значення для заповнення)
   - Внести нові значення
   - Зберегти файл

3. **Імпорт Даних**
   - Відкрити **список показників** (oiHromadaSurvey List View)
   - Натиснути меню **"..."** → **"Імпорт даних з Excel"**
   - Завантажити відредагований файл
   - (Опціонально) Вибрати організацію для валідації
   - Натиснути "Імпортувати"

**Важливо:** Всі дії з експорту/імпорту виконуються через ListView (список показників), а не через окремі документи!

#### API Метод

```python
@frappe.whitelist()
def import_from_excel(file_url: str, org: str | None = None)
```

**Параметри:**
- `file_url` (str): URL завантаженого файлу з Frappe File
- `org` (str, опціонально): ID організації для валідації

**Повертає:**
```python
{
    "status": "success" | "error",
    "updated": 10,  # кількість оновлених записів
    "skipped": 5,   # кількість пропущених
    "errors": [],   # список помилок
    "details": [    # детальна інформація про зміни
        {
            "id": "показник-001",
            "title": "Назва",
            "type": "Кількісні дані",
            "old_value": 10,
            "new_value": 15
        }
    ]
}
```

#### Особливості

✅ **Автоматичне відстеження змін** - Всі зміни автоматично додаються в історію
✅ **Валідація даних** - Перевірка типів та форматів значень
✅ **Пропуск only_admin** - Поля тільки для адміністратора автоматично пропускаються
✅ **Детальний звіт** - Показує що було змінено, пропущено та помилки

❌ **Обмеження:**
- Працює тільки з файлами, згенерованими через `export_org_template`
- Оновлює тільки існуючі показники (не створює нові)
- Не працює з груповими записами

#### Приклад Використання

```javascript
// Клієнтський код (в oiHromadaSurvey.js)
frappe.call({
    method: "orange_inventory.orange_inventory.doctype.oihromadasurvey.oihromadasurvey.import_from_excel",
    args: {
        file_url: "/private/files/template.xlsx",
        org: "ORG-0001"
    },
    callback: function(r) {
        if (r.message.status === "success") {
            console.log(`Оновлено: ${r.message.updated}`);
            console.log(`Пропущено: ${r.message.skipped}`);
        }
    }
});
```

#### Структура Excel Файлу

| Колонка | Назва | Опис | Редагується |
|---------|-------|------|-------------|
| A | Шлях групи | Ієрархія груп | ❌ |
| B | ID | Унікальний ідентифікатор | ❌ |
| C | Назва показника | Повна назва | ❌ |
| D | Тип | Кількісні/Якісні дані | ❌ |
| E | Періодичність | Частота вимірювання | ❌ |
| F | Поточне значення | Значення в системі | ❌ |
| G | **Значення для заповнення** | **РЕДАГУЄТЬСЯ ТУТ** | ✅ |
| H | Примітка | Додаткова інформація | ❌ |

#### Валідація Даних

**Для кількісних показників:**
- Тільки цілі числа ≥ 0
- Автоматична конвертація з float в int

**Для якісних показників:**
- Тільки "Так" або "Ні"
- Регістр має значення
- Автоматична конвертація в булеве значення

#### Результати Імпорту

Після імпорту система показує діалог з:
- Кількістю оновлених записів
- Кількістю пропущених записів
- Таблицею змін (ID, Назва, Старе → Нове значення)
- Списком помилок (якщо є)
